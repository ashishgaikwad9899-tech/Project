# 🛒 E-Commerce Website

A modern and responsive **E-Commerce Website** built using **HTML, CSS, and JavaScript**. This project provides a user-friendly shopping experience with product browsing, search, categories, cart functionality, and a clean responsive interface.

## 🚀 Features

* 🏠 Modern and responsive homepage
* 🔍 Product search functionality
* 📦 Product listing and product cards
* 🏷️ Category-based product filtering
* 🛒 Add to Cart functionality
* ❤️ Wishlist functionality
* 💰 Product price and discount display
* ⭐ Product ratings
* 📱 Fully responsive design
* 🎨 Modern and clean UI
* 🔐 Login/Register UI
* 📄 Product details section

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Interactivity and functionality
